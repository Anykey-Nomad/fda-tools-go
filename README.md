# fda2wav — FDA Audio Converter

[![Go Version](https://img.shields.io/badge/Go-1.27.1+-00ADD8?logo=go)](https://golang.org)
[![License](https://img.shields.io/badge/License-MIT%20%2B%20Non--Commercial-blue.svg)](LICENSE)

Конвертер аудиоформата **FDA** (Fourier / Fast Digital Audio) с полной поддержкой кодека **Relic Codec v1.6**.

FDA — проприетарный аудиоформат компании **Relic Entertainment** (Homeworld, Homeworld 2, Warhammer 40.000: Dawn of War).

## Возможности

- **Декодирование**: FDA → WAV (PCM 16-bit)
- **Кодирование**: WAV (PCM 16-bit) → FDA
- Полный парсинг структуры FDA-файлов
- Декодирование/кодирование через **Relic Codec v1.6** (DCT-based lossy codec)
- Поддержка моно и стерео звука

## Установка

Готовые исполняемые файлы для **Windows** и **Linux** можно скачать в разделе [Releases](https://github.com/Anykey-Nomad/fda-tools-go/releases).

## Сборка

Требуется **Go 1.27.1** или выше.

```bash
cd fda2wav
go build .
```

## Использование

### Простой способ (Drag & Drop)

В Windows вы можете вообще не использовать командную строку. Просто выделите нужные файлы или папки в Проводнике и перетащите их на файл `fda2wav.exe`:

- Перетащите **.fda** файл — он автоматически декодируется в `.wav`.
- Перетащите **.wav** файл — он автоматически закодируется в `.fda` (с битрейтом HQ, 2048).
- Перетащите **папку** — утилита автоматически найдет и сконвертирует все поддерживаемые файлы внутри неё.

### Командная строка (CLI)

Для тонкой настройки или использования в скриптах (bat/bash) доступен интерфейс командной строки:

```bash
fda2wav decode [options] <input.fda>   — Декодирование FDA → WAV
fda2wav encode [options] <input.wav>   — Кодирование WAV → FDA
```

### Битрейты

| Значение | Битрейт/канал | Качество |
|----------|--------------|----------|
| 256 | 22.05 kbps | Низкое |
| 512 | 44.1 kbps | Среднее-низкое |
| 1024 | 88.2 kbps | Среднее |
| 2048 | 176.4 kbps | Высокое |

## Технические детали

### Формат FDA

```
┌─────────────────────┐
│ FDAHeader (24 bytes)│  Signature: "Relic Chunky"
├─────────────────────┤
│ FBIF chunk          │  Метаданные: плагин, пользователь, дата
├─────────────────────┤
│ FDA_ chunk (FOLD)   │  Контейнер для INFO + DATA
│  ├─ INFO chunk (28) │  Каналы, частота, битность, размер фрейма
│  └─ DATA chunk      │  Сжатые аудиоданные
└─────────────────────┘
```

### Relic Codec v1.6

- **Тип**: Lossy, DCT-based (дискретное косинусное преобразование)
- **Размер фрейма**: 32 / 64 / 128 / 256 байт (задаётся параметром BlockBitrate)
- **Сэмплов на фрейм**: 512
- **Каналы**: До 2 (stereo)
- **Частоты**: 11025 / 22050 / 44100 Hz

### Формула битрейта

```
Bitrate (kbps) = BlockBitrate x 86.1328125 x Channels / 1000
```

### Кодирование

Кодер выполняет обратную операцию декодеру:

1. **Forward DCT**: PCM-сэмплы → частотные коэффициенты
2. **Квантизация**: Выбор оптимального экспонента для каждого коэффициента
3. **Упаковка битстрима**: Формирование байтов в формате, понятном декодеру
4. **Запись FDA**: Контейнер с метаданными и сжатыми данными
