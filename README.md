# fda-tools-go — FDA Audio Converter

[![Go Version](https://img.shields.io/badge/Go-1.27.1+-00ADD8?logo=go)](https://golang.org)
[![License](https://img.shields.io/badge/License-MIT%20%2B%20Non--Commercial-blue.svg)](LICENSE)

Конвертер аудиоформата **FDA** (Fourier / Fast Digital Audio) с полной поддержкой кодека **Relic Codec v1.6**.

FDA — проприетарный аудиоформат компании **Relic Entertainment** (Homeworld, Homeworld 2, Warhammer 40.000: Dawn of War).

## Возможности

- **Декодирование**: FDA → WAV (PCM 16-bit)
- **Кодирование**: WAV (PCM 16-bit) → FDA
- **Интерактивный браузер**: при запуске без аргументов открывается TUI-браузер со списком FDA- и SGA-файлов в текущей папке; навигация стрелками, воспроизведение по Enter; по .sga — просмотр каталогов архива прямо в браузере
- **Воспроизведение**: FDA играет прямо в консоли (`--play`), без промежуточного WAV на диске; пауза/продолжение по `Space`, перемотка стрелками, громкость `↑`/`↓`, повтор по `R`
- Полный парсинг структуры FDA-файлов
- Декодирование/кодирование через **Relic Codec v1.6** (DCT-based lossy codec)
- Поддержка моно и стерео звука

## Установка

Готовые исполняемые файлы для **Windows** и **Linux** можно скачать в разделе [Releases](https://github.com/Anykey-Nomad/fda-tools-go/releases).

## Сборка

Требуется **Go 1.27.1** или выше.

```bash
cd fda-tools-go
go build .
```

Для сборки под Windows (64-bit) и Linux (64-bit) сразу можно использовать готовый скрипт — он положит бинарники в папку `dist\`:

```bat
build.cmd
```

> Примечание: скрипт создан для Windows (`cmd`), но собирает и Linux-версию — кросс-компиляция из Go работает из любой ОС. После копирования Linux-бинарника не забудьте: `chmod +x fda-tools-go_linux_amd64`.

## Использование

### Интерактивный браузер (по умолчанию)

При запуске **без аргументов** (двойной клик по exe или `fda-tools-go` в консоли) открывается интерактивный TUI-браузер со списком всех `.fda` и `.sga` файлов в текущей папке:

```
┌─── fda-tools-go ──── File Browser ──────────────────────────┐
│                                                            │
│  ▸ mu_ig_rac_necron.fda                                    │
│    mu_ig_rac_necron_brass.fda                              │
│    mu_ig_rac_necron_perc.fda                               │
│    mu_ig_theme_nightbringer.fda                            │
│                                                            │
│  ↑↓ Navigate   Enter: Play   Q: Quit                      │
└────────────────────────────────────────────────────────────┘

  Selected: mu_ig_rac_necron.fda  (5497.8 KB)
```

Управление:

| Клавиша | Действие |
|---------|----------|
| `↑` / `↓` | Выбор файла в списке |
| `Enter` | Открыть: `.fda` — воспроизвести, `.sga` — войти в архив, папка архива — спуститься вниз |
| `←` / `Backspace` | Назад: из папки архива — вверх, из корня архива — обратно к файлам на диске |
| `Q` или `Esc` | Выход из программы |
| `Ctrl+C` | Прерывание программы |

После завершения воспроизведения (или нажатия `Q` в плеере) браузер автоматически восстанавливается — можно выбрать следующий файл, в том числе оставаясь внутри архива. На время воспроизведения браузер полностью отключается: все клавиши уходят плееру. Буквенные клавиши (`Q`, `J`, `K`) не зависят от раскладки: работают и латиница, и кириллица, в любом регистре.

#### Архивы SGA

Браузер умеет открывать **SGA-архивы Relic** (Dawn of War / Company of Heroes, версии 2 и 4, включая Definitive Edition):

- В списке выберите `.sga` файл и нажмите `Enter` — откроется корень архива, дальше `↑↓`/`Enter` гуляют по каталогам, `←`/`Backspace` возвращает назад.
- Хлебные крошки сверху показывают текущий путь внутри архива.
- Файлы `.fda` внутри архива играют **напрямую, без распаковки на диск**: содержимое извлекается в память (при необходимости распаковывается zlib) и декодируется Relic-кодеком. Экспорт в WAV по `W` работает тоже — файл сохранится в текущую папку.
- Работает и перетаскивание `.sga` на exe — архив откроется сразу в браузере.

Архив открывается только для чтения; сами файлы архива не изменяются.

### Простой способ (Drag & Drop)

В Windows вы можете вообще не использовать командную строку. Просто выделите нужные файлы или папки в Проводнике и перетащите их на файл `fda-tools-go.exe` (можно перетащить сразу несколько объектов):

- Перетащите **.fda** файл — он автоматически декодируется в `.wav`.
- Перетащите **.wav** файл — он автоматически закодируется в `.fda` (с битрейтом HQ, 2048).
- Перетащите **.sga** архив — он откроется в интерактивном браузере для просмотра и воспроизведения `.fda` прямо из архива (не конвертируется).
- Перетащите **папку** — утилита проверит её содержимое и сконвертирует все файлы `.fda` и `.wav` внутри (без захода во вложенные папки).

При этом:

- **Оригиналы не изменяются** — рядом с файлом просто создаётся его копия в противоположном формате.
- Если для файла уже существует версия в противоположном формате (например, рядом с `track.wav` уже лежит `track.fda`), такой файл **пропускается**, чтобы не создавать дубликаты.
- Файлы с другими расширениями игнорируются.
- По завершении программа ждёт нажатия Enter, чтобы окно консоли не закрылось раньше времени, и показывает итоговую статистику (сколько сконвертировано / пропущено / с ошибками).

Битрейт при кодировании из WAV можно изменить, создав ярлык на exe с параметром `-b 1024` (256/512/1024/2048); тогда перетаскивайте файлы на этот ярлык.

### Командная строка (CLI)

Для тонкой настройки или использования в скриптах (bat/bash) доступен интерфейс командной строки:

```bash
fda-tools-go play <file.fda>                — Воспроизведение FDA прямо в консоли
fda-tools-go decode [options] <input.fda>   — Декодирование FDA → WAV
fda-tools-go encode [options] <input.wav>   — Кодирование WAV → FDA
```

Атрибут **`--play`** можно ставить в любое место команды — до или после имени файла:

```bash
fda-tools-go --play <file.fda>
fda-tools-go <file.fda> --play
```
<arg_value><b88a6f17>Воспроизведение работает без перекодировки: FDA декодируется Relic-кодеком прямо в память
и выводится на аудиоустройство, WAV-файл на диске не создаётся. Вместо файла можно указать
папку — проиграются все `.fda` файлы в ней по очереди.

Управление во время воспроизведения:

| Клавиша | Действие |
|---------|----------|
| `Space` | Пауза / продолжить |
| `→` | Перемотка вперёд на 10 секунд |
| `←` | Перемотка назад на 10 секунд |
| `Shift+→` | Перемотка вперёд на 30 секунд |
| `Shift+←` | Перемотка назад на 30 секунд |
| `↑` / `↓` | Громкость +10% / −10% (0–200%) |
| `R` | Включение/выключение повтора (🔁) |
| `Q` или `Esc` | Назад: возврат в браузер (в режиме `play` — пропустить файл) |
| `Ctrl+C` | Прервать воспроизведение и выйти |

Буквенные клавиши (`Q`, `R`, `W`) не зависят от раскладки: работают и на QWERTY, и на ЙЦУКЕН (`Ц`/`К`/`У`), в любом регистре — под CapsLock тоже.

Во время воспроизведения отображается прогресс-бар:

```
▶ [████████████░░░░░░░░░░░░░░░░░░] 1:23 / 4:15
```

## Технические детали

### Формат FDA

```
┌─────────────────────┐
│ FDAHeader (24 bytes)│  Signature: "Relic Chunky"
├─────────────────────┤
│ FBIF chunk          │  Метаданные: плагин, пользователь, дата
├─────────────────────┤
│ FDA_ chunk (FOLD)   │  Контейнер для INFO + DATA
│  ├─ INFO chunk (28) │  Каналы, частота, битность, размер фрейма
│  └─ DATA chunk      │  Сжатые аудиоданные
└─────────────────────┘
```

### Relic Codec v1.6

- **Тип**: Lossy, DCT-based (дискретное косинусное преобразование)
- **Размер фрейма**: 32 / 64 / 128 / 256 байт (задаётся параметром BlockBitrate)
- **Сэмплов на фрейм**: 512
- **Каналы**: До 2 (stereo)
- **Частоты**: 11025 / 22050 / 44100 Hz

### Формула битрейта

```
Bitrate (kbps) = BlockBitrate x 86.1328125 x Channels / 1000
```

### Кодирование

Кодер выполняет обратную операцию декодеру:

1. **Forward DCT**: PCM-сэмплы → частотные коэффициенты
2. **Квантизация**: Выбор оптимального экспонента для каждого коэффициента
3. **Упаковка битстрима**: Формирование байтов в формате, понятном декодеру
4. **Запись FDA**: Контейнер с метаданными и сжатыми данными

### SGA-формат

Чтение SGA-архивов реализовано по исходникам **CDMS / Rainman** (`CSgaFile.cpp`, © Corsix, LGPL 2.1) — спасибо за документацию по формату Relic.
